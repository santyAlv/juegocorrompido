// MANUAL DE SUPERVIVENCIA

1. El objetivo

Sos un estudiante y un malware consciente tomó tu PC. Tenés que rastrearlo, contenerlo y purgarlo antes de que la integridad del sistema llegue a 0%.

2. Cómo se juega

Todo pasa dentro de un escritorio simulado. Abrís programas desde los iconos o el menú Inicio. La herramienta principal es la Terminal: se juega escribiendo comandos reales.

3. Comandos base

  • help — lista de comandos
  • dir — ver contenido de la carpeta
  • cd <carpeta> — entrar · cd .. volver
  • type <archivo> — leer un archivo
  • scan <archivo> — analizar amenazas
  • kill <pid> — terminar un proceso
  • pista — ayuda (cuesta puntos)

4. Integridad = tus vidas

Arrancás con 100%. Perdés integridad si dejás pop-ups abiertos, matás procesos legítimos, confiás en un correo falso o dejás que la CPU colapse. Si llega a 0%, pantalla azul: derrota.

5. Los pop-ups mienten

El malware abre ventanas emergentes. Nunca aceptes lo que ofrecen: cerrarlas o rechazarlas es lo correcto. Cada pop-up abierto te drena integridad con el tiempo.

6. Niveles

  1. Reconocimiento — encontrar el archivo infectado
  2. Contención — matar los procesos del malware
  3. Phishing — clasificar correos reales y falsos
  4. Purga — enfrentamiento final

Puntaje = objetivos cumplidos + decisiones correctas + integridad restante. Las pistas y los errores restan.
